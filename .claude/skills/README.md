# Project skills

The skills in this folder (everything except this README) are copied from
[mattpocock/skills](https://github.com/mattpocock/skills) at commit
`6fd947921b935b7e1e69293a200400f0fdd5c15f` (plugin v1.3.1), MIT licensed;
see `LICENSE-mattpocock-skills`. The set matches the official
`mattpocock-skills` Claude Code plugin. Codex-only `agents/` metadata was dropped.

Claude Code loads skills from `.claude/skills/` automatically, so every session
that checks out this repo (local or cloud) can use them.

To update, re-copy from upstream or run `npx skills@latest update`.
